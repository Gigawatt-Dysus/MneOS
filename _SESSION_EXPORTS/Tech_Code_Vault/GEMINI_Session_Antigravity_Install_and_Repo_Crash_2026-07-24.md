**Eric:** The recent crash of Antigravity IDE 1.23.2 is caused by a synchronization bug involving Gemini 3.6. When the IDE remotely fetches the model catalog and attempts to load or persist Gemini 3.6, the renderer freezes on a cold start. [1, 2]  Method 1: The Offline Launch Workaround  You can bypass the broken boot-up sequence without losing your extensions or configurations: [1]  Disconnect your internet connection entirely (unplug LAN or disable Wi-Fi).  Launch Antigravity 1.23. The IDE will load cleanly because it cannot query the broken model state.  Open your working windows or workspace paths while signed out.  Reconnect your internet and sign back into your account.  Note: Avoid selecting Gemini 3.6 or creating new editor windows during this session to prevent re-freezing. [, 2]  Method 2: Reset to a Clean State  If the app remains frozen, a corrupted cache file is likely forcing the bad state. You can safely trigger a fresh synchronization:  For Windows: Close the app, press Win + R, paste %APPDATA%\Antigravity, and clear out the local cache files (or rename the folder to keep a backup).  Reinstall: If files are deeply corrupted, grab the installer directly from the Google Antigravity Releases Page and reinstall version 1.23.2. Make sure to navigate to Editor Settings → Application → Update Agent Manager and turn off auto-updates to prevent it from happening again. [1, 2, 3, 4, 5]
