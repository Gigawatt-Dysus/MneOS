# Project GIGI: Mnemosyne (MneOS)
## The Olympus Architecture & Mythology

This document defines the core philosophical and structural architecture of MneOS. It maps the technical modules of the sovereign archive to the Greek Pantheon, creating a deeply resonant, mythic mental model for the user interface and backend engine.

### I. The Primordial Triad (The Infrastructure)

#### 1. Mnemosyne (The Sovereign Core)
* **Domain:** Memory, preservation, and the reclamation of the self.
* **Function:** The overarching patron of the project. "Solving for I". The central database and sovereign vault. The ultimate truth of the user's history.

#### 2. Kronos / Chronos (The Temporal Engine)
* **Domain:** Time, chronology, the devouring force, and order.
* **Function:** The backend chronological engine. All timeline-related modules fall under his domain. He provides the raw structure that Mnemosyne fills.
* **Modules:** The Vortex (Event Timeline), The Matrix (Media Timeline).

#### 3. The Moirai / The Fates (The Operational Weavers)
* **Domain:** Destiny, causality, and the weaving of life's threads.
* **Function:** The operational/action layer of the application. They manage the state transitions of memory.
* **Clotho (The Spinner):** Ingestion, starting new threads, creating new Vortex events.
* **Lachesis (The Measurer):** Analytics, pattern recognition, measuring time between nodes.
* **Atropos (The Cutter):** Archiving, pruning toxic threads, executing deletion/closure rituals.

### II. The Nine Muses (The Functional Applications)

The Muses (daughters of Mnemosyne) serve as the specific, user-facing functional modules.

* **Calliope (Epic Poetry):** The Composer (Main writing and authoring hub).
* **Clio (History):** The Vortex & Matrix Archives (Historical record keeping).
* **Erato (Erotic/Lyric Poetry):** The Chamber (AI Chat engine, companions, Brita).
* **Euterpe (Music):** The Atelier / Euterpe Sequence (AI Slideshows, dynamic audio generation, audio playback).
* **Thalia (Comedy):** The Gallery / Lightbox (Daydream Studio, memes, light media).
* **Melpomene (Tragedy):** Reflections (Shadow work, difficult memory processing, redaction).
* **Terpsichore (Dance):** Flow / Workflows (Animations, sequences, ritual UI flows).
* **Polyhymnia (Sacred Poetry):** The Deep Codex (RAG vault, long-term semantic memory storage).
* **Urania (Astronomy):** The Observatory (Future timelines, vision boarding, macroscopic views).

### III. The 3D Virtualized Interface (The Pantheon)

The long-term UI vision for MneOS is a spatial computing environment built via Three.js / React Three Fiber.

**The Space:**
* **The Atrium:** The user loads into a grand, open-air Greek Hall on Mount Olympus.
* **The Vestibules:** Nine temples/halls branch off from the center, each dedicated to a Muse and housing their respective modules.
* **The Kronos Spire:** A towering structural element representing the flow of time.
* **The Loom:** The workshop of the Fates, where timeline threads are visibly woven.

**Phased Rollout Strategy:**
1. **Phase 1 (The 2D Olympus):** Rename internal modules and introduce subtle mythological micro-copy/iconography to the existing React interface.
2. **Phase 2 (The Static Atrium):** Introduce a static 3D/panoramic hub screen where users click altars/doors to load the standard 2D modules.
3. **Phase 3 (The Walkable Sanctuary):** Implement full lightweight 3D navigation, allowing the user to walk the halls of their own memory.
4. **Phase 4 (The Dynamic Loom):** Visualizing data connections as actual glowing threads woven by the Fates across the 3D space.
