# ADR-006: Erato's Palace - The Sovereign Neural Production Studio

## 1. Overview
This document outlines the architectural transformation of "Erato's Palace" from a standard text-to-image modal into a full-scale AI production studio (a "Hollywood in a Box"). The objective is to abstract the complexities of diffusion models, ControlNets, and prompt engineering into intuitive, modular, film-industry-standard workflows.

## 2. Core Architectural Paradigm: The Prompt Compiler
Instead of the user typing monolithic text blocks, MneOS utilizes a **Modular Prompt Compiler**. The user interacts with abstract concepts (Actors, Sets, Cameras, Physics), and the backend compiles these "Pills" into highly engineered prompt payloads formatted specifically for the active neural engine.

---

## 3. Implementation Phasing & Roadmap

### Phase 1: The Engine Room (COMPLETED)
- **The Model Registry (Hot-Swapping):** Dynamic frontend selector routing to Fal.ai models (`FLUX.1 [dev]`, `schnell`, `pro`, `SD3`). The backend maps abstract UI sliders to model-specific parameters (e.g., Inference Steps, CFG Scale).
- **Iterative Base Loop:** The `[Iterate]` button seamlessly drops generated output back into the Structural Base slot, keeping the session "hot" for infinite continuous sculpting.

### Phase 2: The Transparency Layer (NEXT)
- **Prompt X-Ray (The Payload Inspector):** A toggleable terminal view that intercepts and reveals the final compiled text string (including injected modifiers and assets) before it is sent to the model. Prevents "Norman, please correlate" logic clashes.
- **Editable Vision Injections (CtxEd):** Modals on Reference Assets allowing the user to review, edit, and fine-tune the descriptive text generated by Grok Vision. 

### Phase 3: The Director's Control Room
- **The Lock Icon (ControlNet Abstraction):**
  - *Absolute Lock:* Canny/Lineart (Strict geometry).
  - *Structural Lock:* Depth/SoftEdge (Volume remains, details hallucinated).
  - *MoCap Lock (Pose Retargeting):* OpenPose/DensePose (Extracts physical movement/skeletal data from a reference video/actor and drives a fictional AI character, allowing a human actor to puppeteer a completely different digital asset).
  - *Unlocked:* Standard Img2Img (Colors/shapes act as loose suggestions).
- **The Inverter:** Instantly flips the working base asset into an L:R mirror image (vital for 3D model referent cards and turnaround sheets).
- **The Resolution Pipeline:** 
  - Restricts base generation to native model limitations (~1 Megapixel) to prevent anatomical duplication.
  - Adds dedicated **Upscaling** (AuraSR/RealESRGAN/Magnific) for 4K/8K mastering.
  - Adds automatic **Downscaling** for UI thumbnails and avatars.
- **Multiverse Physics:** Scene-level modifier tokens (e.g., standard gravity, zero-g, fantasy rulesets) that override realistic physical constraints.

### Phase 4: "The Back Lot" (Modular Asset Vaults)
A highly organized tagging and "Style Pill" system mimicking a physical film studio. Pills can be "checked out" on a call sheet to dynamically construct the scene prompt.
1. **Casting Dept (Bios & Tag Gallery Integration):** Persistent character profiles ("Bio-Pills"). This directly interfaces with the Matrix Tag Gallery. Real-world individuals (e.g., family, friends) are pulled as standard tags. Fictional characters (e.g., Aria, Brita) are written *back* to the Tag Gallery with an `is_fiction: [universe]` metadata flag to prevent the crossing of real and cinematic data streams.
2. **Wardrobe & Costuming:** Apparel and clothing styles.
3. **Property Control:** The props department (weapons, vehicles, handheld items).
4. **Animal Control:** Biological non-human assets (dogs, cats, dragons, beasts).
5. **Alien Biome:** Intelligent non-human character rulesets (Klingons, elves, monsters).
6. **Makeup Dept:** Specific styling for faces, cybernetics, or cosmetic aesthetics.
7. **Sets & Plate Generation (Locations):** Environments, lighting rigs, and establishing backgrounds. Includes a dedicated mode for "Background Plates" (e.g., a reusable 3-sun alien sky), "Title Cards", and "Chroma Key Stages" (flat green/blue screens) designed specifically for compositing foreground actors in post.
8. **Camera Bay:** Virtual cinematography (Lens types, focal lengths, film stock emulation).
9. **Effects Dept (SFX & Reactions):** Visual modifiers for scene action. Crucially includes "Reaction Cues" and "Eyeline Matches" (e.g., "looking off-camera high left, reacting in horror, orange firelight reflecting on face"). This allows actors to be generated reacting to VFX (explosions, monsters) that will be composited in later during post-production.
10. **Script Dept (The AI Orchestrator):** A dedicated text-editor tool that ingests traditional screenplay formats (Fountain/Final Draft) and uses Grok to parse the scene into a "Call Sheet." The AI automatically extracts the required tags (Characters, Sets, Props, Time of Day) and pre-loads the Compiler with the exact Style Pills needed for the scene.

### Phase 5: The Workflow & Pipeline Integrations
- **The Storyboard Timeline Drawer:** A pull-out tray at the bottom of the studio displaying the linear sequence of shots for the current scene. Allows the Director to "rough in" empty shots, see what needs to be rendered, and visualize exactly how the current active generation fits into the wider cinematic narrative.
- **Session History Ledger:** A scrollable, timeline-based history of the current session's generations, allowing prompt recovery and iterative branching (Terminal Up-Arrow logic).
- **"Phone a Friend" (Muse Assist):** Inline chat assistant (Erato/Brita) pre-loaded with session context to act as a Prompt Engineer, troubleshooting bad outputs and suggesting refinements.
- **Portable Export (Package Session):** A one-click download generating a `.zip` containing all session images, base assets, and a `Session_Log.md` detailing the prompts and workflow.
- **Cross-Session Hotloading:** Drag-and-drop integration from the main MatrixGrid directly into Erato's Palace.
- **Motion & Audio Pipeline:** Seamlessly piping generated static characters into video models (Kling, Luma) and orchestrating ElevenLabs/Lipsync APIs for scripted dialogue.

### Phase 6: The Post-Production Loop (Automated Matrix Tagging)
Erato's Palace natively integrates with the MatrixGrid to act as a Digital Asset Management (DAM) suite for Dailies and review.
- **Auto-Inheritance Tagging:** When `[Accession]` is clicked, the image inherits all modular tags used in its prompt compiler (e.g., `[C:Aria]` applies the `#aria` person tag; `[Camera:35mm]` applies a `#35mm` metadata tag).
- **Bulk Export for Post:** Ability to select a timeline of tagged scenes in the Matrix and bulk-export them for timeline editors (Premiere/Resolve) or social media pipelines.

### Phase 7: The Soundstage Audio Bay (Euterpe's Symphony)
MneOS will feature a dedicated Audio Bay, fulfilling the role of the Muse Euterpe (Music and Lyric Poetry). This is not just blind audio generation, but **Timecode-Synchronized Scoring**.
- **The Composer's Timeline:** Video dailies generated by the visual models are mapped to a timeline. AI music generation (via Suno, Udio, or Fal.ai endpoints) is prompted *against* the scene's SMPTE timecode (e.g., "00:01:15 - Swelling brass as the dragon appears").
- **Multi-Track Stems:** Extracting stems (vocals, drums, strings) for human-in-the-loop mixing and timing adjustments.
- **Voice Acting & Foley:** Integrating ElevenLabs for dialogue generation and targeted sound effects generation to build a complete, film-ready auditory landscape matching the generated visuals perfectly.
